# Updating the live site

Upload everything in this folder to the root of
`github.com/zacharybest-byte/zacharybest-byte.github.io`:

- index.html
- headshot-graded.png, podcast.jpg, favicon.png
- logo-si.png, logo-fansided.png, logo-minute.png, logo-timeinc.png
- robots.txt, sitemap.xml

Steps: open the repo → Add file → Upload files → drag all files in → Commit changes.
Live within a minute or two. Keep the existing CNAME file in the repo.

After it's live: add zacharybest.com in Google Search Console and submit
https://zacharybest.com/sitemap.xml so Google indexes it quickly.
